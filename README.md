# 🚀 Portfolio Express Backend & Admin Dashboard

This is the custom, lightweight Express backend API and Admin Dashboard for the portfolio application.

## 🌟 Features
- **Express REST API**: Clean endpoints for projects, skills, experiences, strengths, and contact form inbox.
- **Resend Email Integration**: Direct email dispatches via official `resend` SDK package.
- **PostgreSQL Database**: Direct connection to Neon DB with automatic schema creation.
- **Admin Dashboard**: Standalone dark glassmorphic web dashboard served at `/admin`.

## 🛠️ Commands

```bash
# Start backend server
npm start

# Development mode
npm run dev
```

- **API URL**: `http://localhost:1337/api`
- **Admin Dashboard**: `http://localhost:1337/admin`
